# AgentGauge AI

**Know which AI agent actually delivers.**

AgentGauge AI is an AI agent benchmarking platform that evaluates and compares coding-agent workflows using execution-based tests.

## Agent Strategies

- DirectCoder: Generates a solution in one pass.
- VerifyCoder: Plans, generates, tests, analyzes failures, and attempts bounded corrections.

## Evaluation Metrics

- Test pass rate
- Reliability
- Execution latency
- Token usage (when available)
- Estimated API cost
- Correction attempts

## Technology Stack

- Python 3.12
- Google Gemini API
- Streamlit
- Pandas
- Plotly
- SQLite
